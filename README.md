# Кафедральная доска объявлений

---

## Описание проекта

Веб-приложение для публикации объявлений и обсуждений внутри университетской кафедры.  
Планируется реализовать три роли пользователей: **администратор**, **преподаватель**, **студент** (плюс гостевой просмотр).

---

## Планируемый функционал

### Общий доступ (гости и все авторизованные)
- Просмотр списка объявлений с пагинацией.
- Просмотр отдельного объявления и комментариев к нему.
- Поиск объявлений по заголовку и тексту.
- Фильтрация по категории и статусу («актуально» / «закрыто»).
- Адаптивная вёрстка (мобильные устройства).

### Студенты (после регистрации/входа)
- Оставление комментариев под объявлениями.
- Личный кабинет: история своих комментариев, избранные объявления (опционально).

### Преподаватели
- Создание объявлений (возможность прикрепить файл – изображение, PDF).
- Редактирование и удаление **только своих** объявлений.
- Закрытие объявления (смена статуса).
- Удаление любых комментариев под **своими** объявлениями.
- Личный кабинет со списком своих объявлений.

### Администратор
- Назначение ролей (преподаватель / студент) и блокировка пользователей.
- Управление категориями объявлений (CRUD).
- Редактирование и удаление **любых** объявлений и комментариев.
- Просмотр статистики (количество объявлений, комментариев за неделю).

## Стек технологий

| Технология | Назначение |
|------------|------------|
| HTML5, CSS3 | Структура, адаптивная вёрстка (Flexbox/Grid, медиазапросы) |
| JavaScript (ES6) | Динамическая фильтрация (Fetch API), всплывающие подтверждения, уведомления |
| PHP 8.1+ | Бэкенд, сессии, работа с БД (PDO), загрузка файлов |
| MySQL 8.0 | Хранение данных: пользователи, объявления, комментарии, категории |
| Git | Контроль версий |

## Планируемая структура базы данных (основные таблицы)

- `users` – пользователи (роль, email, пароль)
- `categories` – категории объявлений
- `announcements` – объявления (заголовок, текст, файл, статус)
- `comments` – комментарии

Полная схема будет добавлена в файл `database/schema.sql` при разработке.
